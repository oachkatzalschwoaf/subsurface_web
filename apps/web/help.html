Anmelden und Logbuch wählen

Beim ersten Öffnen wählst du, wo das Logbuch liegt:

  • Subsurface Cloud: dasselbe Logbuch, das Subsurface Desktop und Mobile synchronisieren. E-Mail und Passwort der Subsurface-Cloud; unter „Erweitert“ lässt sich der Cloud-Server wählen.
  • Eigenes git-Repository: GitHub, GitLab oder ein eigener Server, unabhängig von der Subsurface-Cloud. Nötig sind die https-Adresse, der Branch, der Benutzername und ein Passwort oder Zugriffstoken. Bei GitHub: ein „fine-grained personal access token“ mit Lese- und Schreibrecht auf „Contents“ dieses Repositorys. Der git-Server muss auf dem Server dieser Seite freigeschaltet sein.
  • Nur auf diesem Gerät: ohne Konto. Leer beginnen oder mit einer .ssrf-Datei bzw. einem Backup. Die Daten liegen nur in diesem Browser, also regelmäßig exportieren.

Passwort und Token bleiben nur im Arbeitsspeicher; die App speichert sie nicht. Fragt sie später danach, kann der Passwort-Manager des Browsers aushelfen.

Ist ein Repository noch leer, beginnt es mit einem leeren Logbuch oder mit einer .ssrf-Datei bzw. einem Backup.

Signing in and choosing a logbook

On first use you choose where the logbook lives:

  • Subsurface Cloud: the same logbook Subsurface Desktop and Mobile sync with. E-mail and password of the Subsurface cloud; "Advanced" lets you pick the cloud server.
  • Own git repository: GitHub, GitLab or your own server, independent of the Subsurface cloud. You need the https address, the branch, the user name and a password or access token. On GitHub: a fine-grained personal access token with read and write access to "Contents" of this repository. The git server must be allowed on the server of this page.
  • Only on this device: no account. Start empty or from an .ssrf file or a backup. The data stays in this browser only, so export regularly.

Passwords and tokens stay in memory only; the app does not store them. If it asks again later, the browser's password manager can fill them in.

An empty repository starts with an empty logbook or with an .ssrf file or backup.

Als App installieren

Android: in Chrome Menü ⋮ → „Zum Startbildschirm hinzufügen“ oder „App installieren“. iPhone: in Safari Teilen → „Zum Home-Bildschirm“. Die App öffnet dann im Vollbild und funktioniert offline.

Installing as an app

Android: in Chrome, menu ⋮ → "Add to home screen" or "Install app". iPhone: in Safari, Share → "Add to Home Screen". The app then opens full screen and works offline.

Neue Tauchgänge (FIT-Import)

  1. In Garmin Connect die Aktivität öffnen → Zahnrad → „Datei exportieren“. Das ergibt eine FIT- oder ZIP-Datei.
  2. Im Reiter Neu „FIT- oder ZIP-Dateien wählen“; mehrere auf einmal gehen auch.
  3. Tauchgänge, die schon im Logbuch sind, und Aktivitäten, die keine Tauchgänge sind, werden erkannt und übersprungen.
  4. Für jeden Tauchgang Reise und Tauchplatz wählen oder neu anlegen. Ein neuer Platz bekommt seine Position vom Eintauchpunkt der Uhr, sonst vom Auftauchpunkt; alternativ der aktuelle Standort, eingegebene Koordinaten oder keine Position.
  5. Angaben ergänzen: Buddy, Guide, Anzug, Flasche und Gas, Drücke, Blei, Bewertung, Sicht, Tags, Notizen. „Für alle übernehmen“ kopiert Angaben in alle Tauchgänge.
  6. Hochladen bzw. Hinzufügen. Ohne Netz bleiben die Tauchgänge auf dem Gerät und werden beim nächsten Synchronisieren hochgeladen.

Ausrüstungs-Vorlagen füllen Anzug, Flasche, Gas, Blei, Buddy, Guide und Tags für alle Tauchgänge auf einmal; Drücke bleiben je Tauchgang. „Als Vorlage speichern“ legt eine an, „Zuletzt verwendet“ nimmt die Angaben vom letzten Mal.

New dives (FIT import)

  1. In Garmin Connect open the activity → gear icon → "Export File". This gives a FIT or ZIP file.
  2. In the New tab, "Choose FIT or ZIP files"; several at once work too.
  3. Dives already in the logbook and activities that are not dives are recognised and skipped.
  4. For each dive choose a trip and a dive site, or create them. A new site takes its position from the watch's entry point, otherwise its exit point; or the current location, entered coordinates or no position.
  5. Add details: buddy, guide, suit, cylinder and gas, pressures, weights, rating, visibility, tags, notes. "Copy to all dives" copies details to every dive.
  6. Upload or add. Without network the dives stay on the device and are uploaded with the next sync.

Equipment presets fill suit, cylinder, gas, weights, buddy, guide and tags for all dives at once; pressures stay per dive. "Save as preset" creates one, "Last used" takes the details from last time.

Notizen vor der FIT-Datei

Kein Netz auf dem Boot? Im Reiter Neu gleich nach dem Tauchgang eine Notiz anlegen: ungefähre Uhrzeit, Drücke, Buddy, optional die Position. Kommt später die FIT-Datei, wird die Notiz über die Uhrzeit zugeordnet und füllt das Formular.

Kommt keine FIT-Datei, mit maximaler Tiefe und Tauchzeit „Als Tauchgang ohne Profil übernehmen“. Subsurface zeichnet dafür ein Ersatzprofil.

Notes before the FIT file

No network on the boat? In the New tab, take a note right after the dive: rough time, pressures, buddy, optionally the position. When the FIT file arrives later, the note is matched by time and fills in the form.

If no FIT file will come, enter max. depth and dive time and use "Add as dive without profile". Subsurface draws a stand-in profile for it.

Logbuch und Suche

Der Reiter Logbuch listet die Tauchgänge nach Reisen, mit dem Zeitraum jeder Reise. Das Suchfeld findet Tauchplatz, Buddy, Tag, Notiz oder eine Nummer (#12). Noch nicht synchronisierte Tauchgänge tragen ⏳.

Auf breiten Bildschirmen (PC, Tablet, Handy quer) stehen Liste und Tauchgang nebeneinander. Ein Tipp auf den App-Namen oben führt zurück zum Logbuch.

Logbook and search

The Logbook tab lists the dives by trip, with the date range of each trip. The search field finds site, buddy, tag, notes or a number (#12). Dives not synced yet carry ⏳.

On wide screens (PC, tablet, phone held sideways) the list and the dive are side by side. Tapping the app name at the top leads back to the logbook.

Tauchgang ansehen

Die Tauchgang-Seite zeigt die wichtigsten Werte, das Tiefenprofil und, falls aufgezeichnet, Temperatur und Puls als eigene Streifen auf derselben Zeitachse. Antippen oder Überfahren zeigt die Werte zu diesem Zeitpunkt und die Ereignisse der Uhr (Warnungen, Gaswechsel).

Von hier aus: Bearbeiten, Bild teilen, Bilder hinzufügen, Platz bearbeiten.

Viewing a dive

The dive page shows the main numbers, the depth profile and, where recorded, temperature and heart rate as bands of their own on the same time axis. Tapping or hovering shows the values at that moment and the watch's events (warnings, gas changes).

From here: Edit, Share image, Add pictures, Edit site.

Bearbeiten und Löschen

  • Tauchgang bearbeiten: dieselben Angaben wie beim Import. Hat ein Tauchgang mehrere Flaschen oder Bleiangaben, ändert die App nur die erste.
  • Tauchgang löschen: unten auf der Bearbeiten-Seite. Die anderen Tauchgänge behalten ihre Nummern, wie in Subsurface.
  • Platz bearbeiten: Name und Position; gilt für alle Tauchgänge an diesem Platz.
  • Reise bearbeiten: über den Kopf der Reise in der Liste; Name bzw. Ort und Notizen.

Änderungen werden wie neue Tauchgänge synchronisiert; ohne Netz warten sie auf dem Gerät.

Editing and deleting

  • Edit dive: the same details as at import. If a dive has several cylinders or weights, the app changes only the first one.
  • Delete dive: at the bottom of the edit page. The other dives keep their numbers, as in Subsurface.
  • Edit site: name and position; applies to all dives at that site.
  • Edit trip: from the trip's header in the list; name or location and notes.

Changes are synced like new dives; without network they wait on the device.

Bilder

Auf der Tauchgang-Seite „Bilder hinzufügen“. Die Bilder bleiben auf diesem Gerät; das Logbuch bekommt nur einen Verweis (Topside/<Datum Zeit Platz>/<Name>), der Zeitpunkt im Tauchgang kommt aus den Exif-Daten.

Auf den PC kommen sie mit dem Voll-Export (Daten): ZIP entpacken, dann in Subsurface Datei → „Verschobene Mediendateien suchen“ und den entpackten Ordner wählen.

Pictures

On the dive page, "Add pictures". The pictures stay on this device; the logbook only gets a reference (Topside/<date time site>/<name>), and the moment in the dive comes from the Exif data.

They get to the PC with the full export (Data): unpack the ZIP, then in Subsurface use File → "Find moved media files" and pick the unpacked folder.

Bild zum Teilen

  • Hintergrund: transparent, Farbverlauf (Farben des Schemas), einfarbig oder ein eigenes Bild. Die Bilder des Tauchgangs stehen zur Auswahl; ein Bild beginnt im Format „Original“.
  • Angaben: Tauchplatz, Datum, Uhrzeit und die Werte, die es zu diesem Tauchgang gibt.
  • Profil: Tiefenprofil, Tiefenlinien, maximale Tiefe, Temperatur, Puls; Höhe und Breite mit den Reglern oder mit zwei Fingern auf dem Profil (waagrecht = Breite, senkrecht = Höhe).
  • Jedes Feld lässt sich im Bild an seinen Platz ziehen; mit der Tastatur über die Pfeiltasten.
  • Format (9:16, 4:5, 1:1, 4:3, 16:9, Original), Aufteilung, Schrift, Farben, Schriftfarbe, Schriftgröße, kursiv.
  • „Teilen…“ übergibt das Bild an andere Apps, „Bild speichern“ lädt es als PNG.

Die Einstellungen merkt sich das Gerät für das nächste Bild; ein eigenes Bild muss jedes Mal neu gewählt werden.

Share image

  • Background: transparent, gradient (the theme's colours), solid colour or your own picture. The dive's pictures are offered; a picture starts in the "Original" format.
  • Details: dive site, date, time and the numbers this dive has.
  • Profile: depth profile, depth lines, max. depth, temperature, heart rate; height and width with the sliders or with two fingers on the profile (sideways = width, up and down = height).
  • Every field can be dragged to its place in the image; with a keyboard, use the arrow keys.
  • Format (9:16, 4:5, 1:1, 4:3, 16:9, Original), layout, font, colours, text colour, text size, italic.
  • "Share…" hands the image to other apps, "Save image" downloads it as PNG.

The device remembers the settings for the next image; your own picture has to be chosen again each time.

Karte

„Karte“ im Logbuch zeigt jeden Tauchplatz mit Position als Fahne. Ein Tipp auf die Fahne zeigt den Platz und seine Tauchgänge; ein Tipp auf einen Tauchgang öffnet ihn.

Die Position ist die des Tauchplatzes: beim Import der Eintauchpunkt der Uhr, sonst der Auftauchpunkt, sonst die eingegebene. Korrigieren über „Platz bearbeiten“.

Die Kartenbilder kommen von OpenStreetMap und werden nur geladen, solange die Karte offen ist; dafür braucht es Netz.

Map

"Map" in the logbook shows every dive site with a position as a flag. Tapping a flag shows the site and its dives; tapping a dive opens it.

The position is the dive site's: at import the watch's entry point, otherwise its exit point, otherwise the one entered. Correct it with "Edit site".

The map images come from OpenStreetMap and are loaded only while the map is open; this needs network.

Statistik

Summen (Tauchgänge, Tauchzeit, Tauchplätze), durchschnittlicher Luftverbrauch, Rekorde (tiefster, längster Tauchgang, kältestes und wärmstes Wasser) sowie Werte pro Jahr und pro Reise. Als ungültig markierte Tauchgänge zählen nicht. Der Luftverbrauch (SAC) wird wie in Subsurface berechnet.

Statistics

Totals (dives, dive time, dive sites), average air use, records (deepest and longest dive, coldest and warmest water) and numbers per year and per trip. Dives marked as invalid are not counted. Air use (SAC) is computed as in Subsurface.

Synchronisieren und offline

Die App hält eine Kopie des Logbuchs auf dem Gerät und funktioniert ohne Netz. Neue Tauchgänge und Änderungen warten auf dem Gerät, bis „Synchronisieren“ (im Logbuch oder unter Daten) sie hochlädt.

Beim Synchronisieren holt die App den neuesten Stand vom Server und schreibt ihre Änderungen darauf; sie überschreibt nie etwas. Hat sich das Logbuch inzwischen geändert, versucht sie es einmal neu. In Subsurface Desktop oder Mobile danach synchronisieren, um die Änderungen zu sehen.

Enthält das Logbuch etwas, das die App noch nicht versteht, schreibt sie nicht hinein, zeigt es aber an.

Syncing and offline use

The app keeps a copy of the logbook on the device and works without network. New dives and changes wait on the device until "Sync" (in the logbook or under Data) uploads them.

When syncing, the app fetches the latest state from the server and writes its changes on top; it never overwrites anything. If the logbook changed in the meantime, it tries once more. Sync in Subsurface Desktop or Mobile afterwards to see the changes.

If the logbook contains something the app does not understand yet, it does not write to it, but still shows it.

Export, Import und Backup

  • Export: das ganze Logbuch oder nur die noch nicht synchronisierten Tauchgänge als .ssrf (in Subsurface Desktop: Datei → Importieren); ein Voll-Backup als ZIP, genau so wie gespeichert; der Voll-Export mit Bildern.
  • Import: Tauchgänge aus einer .ssrf-Datei oder einem Backup hinzufügen; es kommen nur fehlende dazu.
  • Backup wiederherstellen: macht das Backup zum aktuellen Stand. Bei einem Logbuch auf einem Server als neue Version, der alte Stand bleibt in der Geschichte.
  • Abmelden und Daten auf diesem Gerät löschen: das Logbuch auf dem Server bleibt. Noch nicht synchronisierte Tauchgänge und Bilder, die nur auf diesem Gerät liegen, gehen verloren.

Export, import and backup

  • Export: the whole logbook or only the dives not synced yet as .ssrf (in Subsurface Desktop: File → Import); a full backup as ZIP, exactly as stored; the full export with pictures.
  • Import: add dives from an .ssrf file or a backup; only missing ones are added.
  • Restore backup: makes the backup the current state. For a logbook on a server as a new version; the old state stays in the history.
  • Sign out and delete data on this device: the logbook on the server stays. Dives not synced yet and pictures kept only on this device are lost.

Reisemodus und Übertragen

Vor einer Reise: unter Daten „In eigenes git kopieren“ legt eine Kopie des Logbuchs in einem leeren git-Repository an; „Ab jetzt mit der Kopie arbeiten“ wechselt dorthin. Das Original bleibt während der Reise unberührt.

Nach der Reise: „Tauchgänge übertragen“ kopiert die Tauchgänge, die dem Ziel fehlen, mit ihren Plätzen und Reisen zum Beispiel in die Subsurface-Cloud. Im Ziel wird nichts geändert oder gelöscht.

Trip mode and transfer

Before a trip: under Data, "Copy to own git" puts a copy of the logbook into an empty git repository; "Work with the copy from now on" switches to it. The original stays untouched during the trip.

After the trip: "Transfer dives" copies the dives the target is missing, with their sites and trips, for example into the Subsurface cloud. Nothing in the target is changed or deleted.

Sprache

Die App folgt der Systemsprache, sonst Englisch. Unter Daten → Sprache (oder auf der Startseite) lässt sich Deutsch oder Englisch fest einstellen; das gilt für dieses Gerät.

Language

The app follows the system language, otherwise English. Under Data → Language (or on the start screen) German or English can be set; this applies to this device.
